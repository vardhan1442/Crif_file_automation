Overview

Panther Lake (PTL) and Wildcat Lake (WCL) are hybrid client SoCs built from two core IPs:

  • Cougar Cove — the performance (P-) core, a deep out-of-order design with a conventional Front End → Out-of-Order (Alloc/RAT/ROB) → Execution → Memory Execution (load/store) → Mid-Level Cache pipeline.
  • Darkmont — the efficiency (E-) core, whose PerfMon taxonomy groups most counters under generic Array (ARR) and Bus-Interface-Unit (BIU) buckets rather than exposing the same fine-grained OOO/EXE split as Cougar Cove.

Every event below carries an EventCode/UMask pair (the values you program into IA32_PERFEVTSELx / core PMU MSRs) plus the RTL Unit tag used internally to say which pipeline block the counter instruments. This page groups all 595 events by that Unit tag into pipeline stages, shows where each stage sits with an SVG block diagram, and lets you search/filter the full list.
